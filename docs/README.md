# Documentation

Use this folder for design notes, setup explanations, and specifications as the project develops. No gameplay design is approved by the initial project layout.

The main handoff files live at the top of the repository:

| File | What it tells you |
| --- | --- |
| [README.md](../README.md) | What the project is and how to get started. |
| [AGENTS.md](../AGENTS.md) | Instructions for Codex and other contributors. |
| [PROJECT_STATUS.md](../PROJECT_STATUS.md) | Where development stands and what to do next. |
| [ROADMAP.md](../ROADMAP.md) | Milestones and unfinished tasks. |
| [DECISIONS.md](../DECISIONS.md) | Choices already made and their reasons. |
| [BUGS.md](../BUGS.md) | Known problems and how to reproduce them. |
| [TEST_LOG.md](../TEST_LOG.md) | Checks that ran and their actual results. |

Before implementing a feature, write a small specification here when the task needs one. Explain the player experience, limits, and how to tell whether it works. Keep ideas, approved plans, and implemented behavior clearly distinguished.
